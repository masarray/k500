Native control.
Hardware truth.

SonKuPik K500 is a native Qt 6 Windows control and preset-engineering application for the K500 karaoke processor—built around authoritative device readback, verified protocol writes, bit-preserving presets, and fail-closed permanent transactions.

Engineering first

Not a skin over a generic editor.

The application models the K500 as real hardware with state authority, transaction boundaries, unknown bytes, and protocol evidence. UI completeness never outranks device safety.

01

Device truth first

LIVE starts only after heartbeat, handshake, and a complete 939-byte active-memory readback.

02

Bit-preserving .k500

Exact 1144-byte validation, byte-identical no-op handling, controlled mutation, and verified 656-byte slot conversion.

03

Official + Local library

Bundled SONKUPIK presets and user-owned LOCAL presets live in one validated collection without losing provenance.

04

Validated preset sync

Official updates are checked before cache promotion; network or validation failure keeps the last-known-good source.

05

Native permanent Upload

Single Upload and Mass Upload reuse the proven Store chain, explicit slot mapping, ACKs, and post-write hardware resync.

06

Crash-resistant Qt UI

Fixed EQ page/model lifetimes avoid unsafe 10/7/5-band hot swaps; runtime navigation stress tests guard the fix.

Safety by architecture

Separate intent from authority.

A selected file is not hardware. A preview is not hardware. A transfer list is not hardware. The K500 becomes editor truth only through verified readback.
