BUILT CAREFULLY UNDER THE HOOD

Simple for users. Strict with the hardware.

The friendly interface sits on top of a conservative device model: hardware readback is authoritative, preset files are validated, unknown commands stay read-only, and permanent writes use verified transactions.

Hardware-firstFull device readback before LIVE editing.
Preset integrityValidates native .k500 containers and preserves unknown bytes.
Fail closedUncertain destructive actions stop instead of guessing.
Open sourceProtocol behavior and engineering decisions are inspectable on GitHub.
