GET STARTED

From download to tuning in three steps.

1

Install

Download the Windows Setup package. A portable ZIP is also available if you prefer no installation.

2

Connect the K500

Connect the processor over USB HID. SonKuPik performs the device handshake and reads the current state.

3

Tune with confidence

Choose Music, Mic, Effect or Output and work from the controls already synchronized with your device.

Important: Windows binaries are currently unsigned open-source builds, so SmartScreen may show a warning on first download. Published releases include SHA-256 verification metadata.

PRESETS WITHOUT SURPRISES

Try a preset before you permanently write it.

SonKuPik keeps hardware state, the selected PC preset, offline preview, and permanent upload as separate concepts. That makes the workflow easier to understand and reduces accidental writes.

BUILT AROUND DEVICE TRUTH

The screen should reflect the K500 — not an old value left in the UI.

Before LIVE editing, SonKuPik performs its handshake and complete device readback. Permanent actions are kept explicit, and unsupported write commands remain unavailable rather than being guessed.
