# Source Lineage

SonKuPik K500 began as a standalone native Qt extraction from the earlier `masarray/ktv-studio-mixer-pro` project:

- historical source repository: `masarray/ktv-studio-mixer-pro`
- historical source branch: `qt-native-ui-prototype`
- historical source commit: `3427b1b482bad6560b46a5690d59b2edf55eec3c`

That information is retained for provenance only.

The authoritative source of SonKuPik K500 is now this repository:

`https://github.com/masarray/k500`

The first public stable line is **v1.0.x**. Current architecture, protocol guards, preset library, release workflows, documentation, and issue tracking should be taken from this repository rather than reconstructed from the historical Electron/web application.

The historical donor remains valuable as protocol evidence where explicitly referenced by the golden-vector/parity documentation, but it is not the runtime dependency or current product source tree.
